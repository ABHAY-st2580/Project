#Tile Stock Management System

A desktop-based stock and sales management system designed for tile shops to efficiently manage inventory, sales transactions, and customer records.
The system also integrates data mining techniques to generate business insights from sales data.

#Features

1. Inventory Management
Track tile stock levels and manage product details.

2. Sales Entry System
Record customer transactions and purchased tiles.

3. Customer Records
Maintain customer information and transaction history.

4. Machine Learning Insights
Uses Apriori and FP-Growth algorithms to identify frequently purchased tile combinations.

5. Data Visualization
Sales trends and demand analysis using Matplotlib.

6. Interactive GUI
User-friendly interface built using Tkinter / CustomTkinter.
